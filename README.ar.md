# عميل Giles · Giles VPN GUI

> عميل VPN حديث مبني باستخدام **Flutter**، يعتمد على نواة **[sing-box](https://sing-box.sagernet.org/)** العالمية،  
> ويعمل بشكل أصلي على **Android / iOS / macOS / Windows** — مع **دعم كامل لجميع بروتوكولات sing-box**.

---

## 🪔 نبذة عن المشروع

**عميل Giles** (الاسم التجاري: **Giles VPN GUI**) هو عميل بروكسي من الجيل التالي، مصمم للمستخدمين والشركات الذين يبحثون عن الأداء والأمان والتخصيص العميق.

- **متعدد المنصات**: قاعدة شفرة واحدة بـ Flutter تعمل على Android وiOS وmacOS وWindows بشكل أصلي — مع خطط لإضافة Linux والويب لاحقاً.
- **نواة قوية**: تكامل كامل مع [sing-box](https://sing-box.sagernet.org/) يدعم **جميع** المداخل والمخارج والبروتوكولات.
- **تغطية شاملة للبروتوكولات**: VMess / VLESS، Trojan، Shadowsocks، Hysteria / Hysteria2، TUIC، WireGuard، NaïveProxy، Brook، ShadowTLS، SSH — كل ما يدعمه sing-box.

> 💡 هذا المستودع مخصص لـ **العروض التجارية وطلبات التطوير المخصص**.  
> يمكن للمؤلف تنفيذ **مشاريع تطوير مخصص كاملة** — العلامة التجارية، الواجهة، البروتوكولات، الاشتراكات، قواعد التوجيه، العقد المدمجة، التعبئة والنشر في المتاجر.
